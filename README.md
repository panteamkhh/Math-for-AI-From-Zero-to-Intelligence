# 🧠 Math for AI: From Zero to Intelligence

### 80 Days of Math for AI

A structured micro-learning journey to build the mathematical foundations behind Artificial Intelligence — one intuition-first lesson a day.

---

## 🎯 Goal

Build the mathematical intuition behind AI, Machine Learning, and Data Science through a layered, progressive learning path — **understanding *why* it works, not memorizing formulas.**

## 📚 Structure

- **8** Learning Layers
- **80** Days
- **~10 minutes** per day
- Every day = 🎯 Intuition → 💡 ML/AI Application → 📝 Mental Exercise → 🧪 Hands-on code

---

| # | Layer | Days | What you'll build |
|---|---|---|---|
| 🧩 | **[Layer 1 — Mathematical Thinking Foundations](layer-1/)** | Days 1–5 | Sets, distance, scale, patterns — the mental habits underneath every model |

| 🚀 | **Layer 8 — Mathematics of Modern AI** | Days 56–80 | Backprop, attention, embeddings — where everything converges into transformers |

## 🚀 Why This Repository?

Most AI learners jump directly into models and libraries. This roadmap focuses on building the **mathematical intuition** needed to understand *how* AI systems actually work — so the math stops being a wall and starts being a lens.

Each lesson is intentionally short (~10 minutes) and follows the same four-part structure:

- **🎯 Intuition** — what the concept really means, in plain language
- **💡 ML/AI Application** — exactly where it shows up in real ML/AI work
- **📝 Mental Exercise** — a short prompt to lock the idea in
- **🧪 Hands-on** — a runnable code snippet that makes it concrete
